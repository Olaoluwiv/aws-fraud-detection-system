# VaultGuard Frontend Prototype

A browser-only fraud monitoring dashboard prototype built with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Open the `frontend` folder in VS Code.
2. Open `index.html` with the Live Server extension, or open the file directly in a browser.
3. Click each sidebar item to explore its page.
4. Try search, filters, Create Alert, Inspect, Add sample, and CSV export.

## Important
- This is a frontend prototype using synthetic in-memory sample records.
- No backend, database, AWS service, or trained machine-learning model is connected yet.
- Sample risk decisions are not real fraud assessments.
- Currency selection changes display formatting only; it does not convert amounts.
- Records reset when the browser page reloads.
